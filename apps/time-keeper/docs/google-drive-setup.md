# 구글 드라이브 동기화 연결하기

짜달시리 타이머는 서버가 없습니다. 기록은 **내 구글 드라이브**에 올라가고, 그 열쇠(OAuth 클라이언트)도 **내가 직접** 만듭니다.
한 번만 하면 되고 10분쯤 걸립니다. 화면 이름은 구글 클라우드 콘솔이 바뀌면 조금 다를 수 있습니다.

> 왜 직접 만드나요? 앱을 공개 저장소에서 나눠 주기 때문에 열쇠를 앱에 넣어 두면 누구나 꺼내 쓸 수 있습니다.
> 각자 자기 열쇠를 쓰면 그런 걱정이 없고, 앱은 **이 앱이 만든 파일만** 볼 수 있습니다(`drive.file` 권한). 내 드라이브의 다른 파일은 보지 못합니다.

## 1. 프로젝트 만들기

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 내 구글 계정으로 들어갑니다.
2. 위쪽의 프로젝트 선택 → **새 프로젝트** → 이름은 아무거나(예: `jjadalsiri-timer`) → **만들기**.

## 2. 구글 드라이브 API 켜기

1. 메뉴 → **API 및 서비스** → **라이브러리**.
2. `Google Drive API`를 찾아 → **사용**(Enable).

## 3. 동의 화면 만들기

1. 메뉴 → **Google Auth Platform** → **브랜딩**(Branding).
2. 앱 이름(예: `짜달시리 타이머`)과 사용자 지원 이메일(내 이메일)을 넣고 **다음**.
3. 대상(Audience)은 **외부**(External)를 고르고, 연락처 이메일을 넣은 뒤 **만들기**.
4. **데이터 액세스**(Data Access) → **범위 추가 또는 삭제** → `.../auth/drive.file`(Google Drive API, "이 앱으로 연 파일만") 체크 → **저장**.

## 4. 앱 게시하기 ⚠️ 꼭 하세요

1. **대상**(Audience) 화면에서 **앱 게시**(Publish app) → 확인.
2. 게시 상태가 **프로덕션 단계**(In production)가 됐는지 확인합니다.

이걸 안 하면 앱이 "테스트" 상태로 남아서 **7일마다 로그인이 풀립니다** (구글 정책).
`drive.file`은 구글이 "민감하지 않은 권한"으로 분류한 권한이라, 구글 심사를 받지 않고 게시해도 나 혼자 쓰는 데는 문제가 없습니다. 심사를 안 받았기 때문에 6번에서 "확인하지 않은 앱" 경고가 한 번 뜹니다.

## 5. 클라이언트(열쇠) 만들기

1. **Google Auth Platform** → **클라이언트**(Clients) → **클라이언트 만들기**.
2. 애플리케이션 유형: **데스크톱 앱**(Desktop app). 이름은 아무거나 → **만들기**.
3. 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`)와 **클라이언트 보안 비밀번호**를 복사해 둡니다. (JSON 다운로드를 받아 두면 나중에 다른 컴퓨터에서 쓰기 편합니다.)

## 6. 앱에 넣고 연결하기

1. 짜달시리 타이머 → **설정** 탭 → **구글 드라이브 동기화**.
2. 클라이언트 ID와 보안 비밀번호를 붙여 넣고 **구글로 연결**.
3. 브라우저가 열리면 내 구글 계정을 고릅니다.
4. **"Google에서 확인하지 않은 앱"** 화면이 나오면: 내가 만든 앱이라 정상입니다. **고급** → **(앱 이름)(으)로 이동** → **계속/허용**.
5. 브라우저에 "연결됐어!"가 뜨면 닫아도 됩니다. 앱에 "마지막 동기화 방금"이 보이면 끝.

## 다른 컴퓨터에서

**같은 클라이언트 ID와 보안 비밀번호**를 넣고 같은 구글 계정으로 연결하세요.
`drive.file` 권한은 "이 클라이언트가 만든 파일"만 보이기 때문에, 컴퓨터마다 다른 클라이언트를 만들면 서로의 기록이 안 보입니다.

## 알아 두면 좋은 것

- **언제 동기화되나요?** 앱을 켤 때, 5분마다, 기록이 끝나고 15초 뒤, 그리고 **지금 동기화**를 누를 때.
- **진행 중인 기록**은 끝난 뒤에 올라갑니다.
- **드라이브에 생기는 것:** `Jjadalsiri Timer` 폴더 하나, 그 안에 컴퓨터마다 `sessions-<기기ID>.json` 파일 하나. 컴퓨터마다 자기 파일에만 써서 서로 덮어쓰지 않습니다.
- **인터넷이 없어도** 타이머·통계는 그대로 됩니다. 다른 컴퓨터 기록은 마지막으로 받아 둔 것이 보이고, 연결되면 다시 맞춥니다.
- **열쇠는 어디 저장되나요?** 이 컴퓨터의 운영체제 보안 저장소(Windows DPAPI / macOS 키체인)로 암호화해서 앱 데이터 폴더에 둡니다.
- **연결 끊기**를 누르면 이 컴퓨터의 열쇠와 받아 둔 기록을 지우고 구글 쪽 권한도 철회합니다. 드라이브의 파일은 그대로 남습니다(지우려면 드라이브에서 폴더를 지우세요).
- **"로그인이 풀렸어"**가 뜨면: 4번(앱 게시)을 했는지 확인하고 **다시 연결**하세요.
