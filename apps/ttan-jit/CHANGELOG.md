## [Unreleased]
### Added
- 패널 진하기(투명도) 설정 20%~100%: 낮추면 뒤 화면이 비쳐서 옆에서 흘깃 봐도 잘 안 보임 (#49)
- 체스 무르기: 내 마지막 수(와 컴퓨터 응수)를 되돌림, 여러 번 가능, 끝난 판에서도 가능 (#47)
- 체스 난이도 4단계: 더 약한 '쉬움' 추가, 기존 쉬움·보통·어려움은 보통·어려움·매우 어려움으로 (저장된 판은 같은 세기로 이어짐). 새 판 기본값은 쉬움 (#47)
- 여러 모니터: 설정 창에 모니터 배치 그림, 어느 모니터의 어느 모서리에 패널을 띄울지 고르기. 옆 모니터와 맞닿아 커서가 넘어가는 모서리는 흐리게 막고, 고른 모니터가 빠지면 주 모니터로 (#45)
- 앱 생성: Electron + React + Vite + TS 뼈대, 체스/스도쿠 탭 자리만 있는 패널 창, 단일 인스턴스, Windows(.exe)·macOS(.dmg) 설치 파일 설정 (#32)
- 화면 모서리(기본 오른쪽 위)에 커서를 0.5초 올려 두면 패널이 나타나고, 패널을 벗어나면 바로(약 16ms) 사라짐. 포커스를 뺏지 않음 (#33)
- 작업표시줄·Dock·Alt+Tab 에 나타나지 않고, 항상 위·화면 공유/스크린샷에서 패널 숨김 (#33)
- 스도쿠: 답이 하나뿐인 문제를 쉬움·보통·어려움으로 자동 생성, 메모·지우기·되돌리기·틀린 칸 빨간 표시·풀이 시간(숨기면 멈춤), 키보드(숫자·화살표·N·Ctrl+Z) (#34)
- 하던 판을 저장해 앱을 다시 켜도 이어서 하기, 마지막에 하던 게임 탭으로 열림 (#34)
- 체스: 컴퓨터 상대(쉬움·보통·어려움), 백·흑·무작위 선택, 클릭 또는 끌어서 두기, 갈 수 있는 칸·마지막 수·체크 표시, 체크메이트·무승부 판정, 하던 판 저장 (#35)
- 설정 창: 모서리(네 곳 중 선택)·나타나기까지 시간(0.2~1.5초)·패널 크기(작게/보통/크게)·트레이 아이콘·화면 공유 숨김·스도쿠 틀린 칸 표시, 앱 종료 버튼 (#36)
- 트레이 아이콘(점 격자): 설정·종료 메뉴, 설정에서 끌 수 있음. 패널 톱니바퀴로도 설정 열기, 앱을 한 번 더 실행하면 설정 창이 뜸 (#36)
- 한국어/영어: 설정에서 시스템 언어·한국어·English, 트레이 메뉴·설정 창 제목 포함 (#37)
