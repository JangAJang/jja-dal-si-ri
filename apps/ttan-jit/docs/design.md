# ttan-jit 0.1.0 설계

2026-10-20 grill 인터뷰로 합의한 내용 (#30). 구현은 아래 "구현 이슈 나누기"의 단위로 이슈를 만들어 추적한다.

## 한 줄 요약
마우스 커서를 화면 모서리에 잠깐 올려 두면 체스판이나 스도쿠 패널이 나타나고, 커서가 패널을 벗어나면 **아무것도 없었던 것처럼** 사라지는 데스크톱 딴짓 앱. 표시 이름 **짜달시리 딴짓**, 폴더·태그 이름 `ttan-jit`.

## 형태·배포
- Windows `.exe` / macOS `.dmg` 데스크톱 앱. Electron + React + Vite + TypeScript (루트 `CLAUDE.md`의 데스크톱 앱 예외). `docker-compose.yaml`·포트 없음.
- 태그 `ttan-jit/v*` 푸시 → `.github/workflows/ttan-jit-release.yml`이 두 OS를 빌드해 GitHub Releases에 올린다 (time-keeper 워크플로 복사).
- 코드 서명 없음. 첫 실행 보안 경고 우회법은 앱 `README.md`에 안내한다.
- 웹 페이지·브라우저 확장은 고려했지만 버렸다. 업무 화면 위 어디서나 떠야 하므로 OS 창이 필요하다.

## 핫존 (모서리)
- **주 모니터의 네 모서리 중 하나**에 둔다. 설정에서 고르고, 기본값은 **오른쪽 위**다.
  - 오른쪽 아래(Windows 바탕화면 보기)·왼쪽 위(mac 애플 메뉴)와 덜 겹치는 자리라서 기본값으로 골랐다. mac 핫코너를 같은 모서리에 설정해 두면 둘 다 동작하므로 README에 안내한다.
  - 주의: Windows에서 최대화된 창의 닫기(X) 버튼이 오른쪽 위에 있다. 0.5초 지연 덕분에 X를 바로 누르면 패널이 끼어들지 않는다.
- 핫존은 모서리 꼭짓점에서 작은 정사각형(약 8×8 논리 px)이다. 커서를 모서리로 던지면 화면 끝에서 멈추므로 찾기 쉽다.
- **다중 모니터** (#45에서 변경): 처음엔 주 모니터만 썼지만, 사용자 환경(주 3440×1440 양옆에 1920×1080, 옆 모니터는 y≈361~368부터)에서 주 모니터 아래쪽 모서리가 막혀 패널이 안 뜨는 일이 실제로 생겨, **어느 모니터의 어느 모서리를 쓸지 고르게** 했다.
  - 설정 창에 OS 배치를 비율대로 줄인 그림을 그리고, 모니터마다 네 모서리 버튼을 둔다(번호는 왼쪽부터 1, 2, 3…, 주 모니터 표시).
  - **막힌 모서리**: 꼭짓점에서 가로나 세로로 한 칸 나간 자리에 다른 모니터가 있으면 커서가 멈추지 않으니 흐리게 하고 못 고르게 한다. 대각선으로만 닿은 경우는 막힌 것으로 보지 않는다.
  - 저장은 `displayId`(Electron `display.id`) + 모서리. 고른 모니터가 연결돼 있지 않으면 주 모니터를 쓰고 설정 창에 알린다. 배치가 바뀌어 고른 모서리가 막히면 설정 창에 경고한다.
  - 모니터 배치·해상도·배율이 바뀌면(`screen` 이벤트) 떠 있던 패널을 숨기고, 다음에 뜰 때 새 위치로 뜬다.
- **감지 방식** (구현 완료 #33 — `src/main/panel.ts`, `src/shared/hotzone.ts`): 숨겨진 동안에는 창을 실제로 숨긴다(`hide`). main 프로세스가 `screen.getCursorScreenPoint()`로 커서 위치를 확인한다. 숨김 중에는 50ms마다, 패널이 보이는 동안에는 한 틱(≈16ms)마다 본다. 렌더러 `mouseleave`로 즉시 숨기려 했지만, 포커스 없는 toolwindow에는 이벤트가 오지 않아(Windows 실측) 폴링만 쓴다. 투명한 클릭 통과 창을 계속 띄우는 방식은 버렸다. 흔적이 남고, OS별로 클릭 통과·호버 감지가 불안정하다.

## 나타나기·사라지기
- 커서가 핫존에 **0.5초 머물면** 패널이 나타난다. 스쳐 지나갈 때 뜨는 것을 막기 위해서다.
- 커서가 **패널 밖으로 나가면 즉시** 사라진다. 애니메이션이나 유예 시간은 없다. 누가 다가오면 커서만 치우면 된다.
  - 패널은 핫존 모서리에 붙어서 뜨므로, 나타난 순간 커서는 이미 패널 안에 있다.
  - 체스 기물을 끌다가 패널을 벗어나도 즉시 숨기고, 끌던 수는 취소한다.
- 지연 시간(기본 500ms)은 설정에서 조절할 수 있다. 숨김은 늘 즉시이며 조절할 수 없다.
- **포커스**: 패널은 포커스를 뺏지 않고 뜬다(`showInactive`). 그래서 타이핑 중에 모서리를 스쳐도 입력이 끊기지 않는다. 패널 안을 클릭해야 키보드 입력(스도쿠 숫자 등)을 받는다. 숨길 때는 이전 앱으로 포커스를 돌려준다.
- 패널은 항상 위(`alwaysOnTop`, 전체 화면 앱 위 포함 여부는 구현 때 OS별로 확인)에 뜬다.

## 흔적 지우기
- 작업표시줄·Dock·Alt+Tab(앱 전환기)에 나타나지 않는다 (`skipTaskbar`, mac `app.dock.hide()`).
- **트레이(메뉴 막대) 아이콘** (구현 완료 #36 — `src/main/tray.ts`): 기본으로 보인다. 아이콘은 3×3 점 격자(mac 템플릿 이미지·Windows 회색), 툴팁은 `ttan-jit`. 메뉴는 설정·종료(Windows는 아이콘 클릭으로도 설정). 설정에서 **트레이 아이콘까지 끌 수 있다.**
  - 패널 탭 줄 오른쪽 톱니바퀴로도 설정 창을 연다. 트레이를 끄면 설정과 종료는 이 길로만 들어간다.
  - 복구 경로: 앱을 **한 번 더 실행하면** 설정 창이 뜬다 (단일 인스턴스, `second-instance` 이벤트). 설정 화면과 README에 이 방법을 적는다.
- 창 제목·트레이 아이콘·툴팁은 게임처럼 보이지 않는 수수한 이름과 모양으로 한다.
- **화면 공유에서 숨김**: 패널이 화면 공유·녹화·스크린샷에 찍히지 않게 한다 (`setContentProtection(true)`). 기본은 켬이고 설정에서 끌 수 있다. Windows 10 2004 이전에서는 검은 사각형으로 찍힐 수 있다.

## 게임 공통
- 패널 위쪽의 작은 탭 **[♟ 체스] [9 스도쿠]**로 바꾼다. 다시 뜨면 **마지막에 하던 게임**이 나온다.
- 두 게임의 상태는 따로 유지한다.
- **숨기면 멈춘다.** 다시 뜨면 그 자리부터 이어서 한다. 스도쿠 풀이 시간도 숨겨진 동안에는 가지 않는다.
- **앱을 꺼도 이어진다.** 진행 중인 판과 마지막 게임을 `userData/ttan-jit-games.json`(`version: 1`)에 저장하므로 재실행·재부팅 후에도 이어서 한다 (구현 #34 — `src/main/gameStore.ts`). 깨진 파일이면 새 판으로 시작한다.

## 체스 (구현 완료 #35 — `src/shared/chess.ts`, `chessWorker.ts`, `views/ChessView.tsx`)
- **컴퓨터 상대**다. 인터넷 없이 내장 엔진으로 둔다. 온라인 대전은 버렸다. 상대를 기다리게 하는 구조라서 "숨기면 멈춤"과 맞지 않는다.
- 엔진은 **js-chess-engine 2.4.6(MIT)** 이고, 규칙 검사·판정·저장은 **chess.js 1.4.0(BSD-2)** 로 한다.
  - 난이도 → 엔진 (#47에서 4단계로): 쉬움 레벨 1(무작위 폭 200cp) · 보통 레벨 2(60cp) · 어려움 레벨 3(20cp) · 매우 어려움 레벨 4(0cp). "너무 어렵다"는 피드백으로 더 약한 쉬움을 넣고 기존 셋을 한 칸씩 올렸다. 새 판 기본값은 쉬움. Node에서 잰 한 수 계산 시간은 레벨 2·3·4가 평균 8 / 17 / 79ms(최대 152ms)다.
  - 저장 형식 2: 형식 1의 easy·medium·hard는 같은 엔진 세기인 medium·hard·veryHard로 옮긴다.
  - 엔진이 너무 빨리 두면 정신없어서 최소 350ms는 "생각 중…"을 보여 준다.
  - stockfish(WASM)는 가장 강하지만 GPLv3다. 설치 파일에 넣으면 앱을 GPL로 공개해야 해서 쓰지 않는다. 레포에는 LICENSE가 없다.
- 난이도는 쉬움/보통/어려움 3단계, 내 색은 흰/검/무작위 중에서 고르며 [새 판]이 있다(스도쿠처럼 하던 판이 있으면 두 번 눌러야 함). 시간 제한은 없다. 내 색이 아래로 오게 판을 뒤집는다.
- 클릭 두 번(고르고 → 갈 칸) 또는 끌어서 둔다. 갈 수 있는 칸·마지막 수·체크된 킹을 표시한다. 폰이 끝 줄에 닿으면 퀸으로 승격한다(승격 기물 고르기는 두지 않음).
- 판정: 체크메이트(이겼다!/졌다…), 스테일메이트·삼수 동형·기물 부족·50수는 무승부.
- **무르기** (#47): 판 아래 [무르기]. 내 마지막 수까지 되돌려 다시 내 차례로 — 내 차례면 컴퓨터 응수와 내 수 두 수, 컴퓨터가 생각 중이거나 내 수로 판이 끝났으면 내 수 하나. 여러 번 가능, 끝난 판에서도 가능. 흑일 때 컴퓨터 첫 수는 무르지 않는다. 생각 중이던 계산은 수 개수가 달라져 버려진다.
- 배치: 툴바(난이도·색·새 판) / 판 34px × 8 / 상태 문구·[무르기] 줄.
- 저장은 시작 위치부터의 수 목록(UCI)만 하고, 읽을 때 실제로 다시 둬 봐서 안 되면 새 판으로 시작한다.
- 엔진 계산은 Web Worker에서 해서 화면이 멈추지 않게 한다. 계산 중에 숨겨지면 계산을 마치고 수를 둔 뒤, 다음에 뜰 때 보여준다(숨긴 창의 타이머가 늦춰지지 않게 패널 창은 `backgroundThrottling: false`).

## 스도쿠 (구현 완료 #34 — `src/shared/sudoku.ts`, `sudokuGame.ts`, `views/SudokuView.tsx`)
- 문제는 **앱에서 자동 생성**하고, **해가 하나뿐인** 문제만 낸다. 난이도는 쉬움/보통/어려움 3단계다.
  - 목표 힌트 수는 쉬움 38 · 보통 30 · 어려움 24다(유일해를 지키느라 조금 더 남을 수 있음).
  - 쉬움·보통은 싱글(칸에 들어갈 숫자가 하나뿐 / 단위에서 숫자가 갈 칸이 하나뿐)만으로 풀리는 문제만 낸다. 어려움은 싱글만으로는 안 풀리는 문제를 낸다(20번 시도 안에 못 찾으면 마지막 것).
  - 생성 시간은 어려움도 평균 약 3ms라 화면 스레드에서 바로 만든다.
- [새 판]은 하던 판이 있으면 "진짜 새 판?"으로 바뀌어 3초 안에 한 번 더 눌러야 한다(대화상자 대신). 난이도 상자는 다음 새 판의 난이도다.
- 같은 숫자를 다시 넣으면 지워지고, 넣은 숫자는 같은 행·열·상자의 메모에서 빠진다. 선택한 칸의 행·열·상자와 같은 숫자를 옅게 칠한다. 9개를 다 쓴 숫자 버튼은 흐려진다.
- 다 풀면 판 위에 "다 풀었다!"와 풀이 시간을 띄우고, 입력·되돌리기·시간을 멈춘다.
- 편의 기능은 메모(후보 숫자), 되돌리기, 틀린 칸 표시(설정에서 끄기), 풀이 시간이다.
- 입력은 칸 클릭 + 숫자 키 또는 패널 안 숫자 버튼이다(키보드 포커스가 없을 때도 클릭만으로 풀 수 있게). 키보드: 1~9, Backspace/Delete/0 지우기, 화살표 이동, N 메모 모드, Ctrl/Cmd+Z 되돌리기.
- 생성·검증 로직은 Electron 없는 순수 함수(`src/shared/`)로 두고 vitest로 테스트한다(유일해 보장 포함).

## 화면·디자인
- 패널 크기는 3단계(작게/보통/크게)이고, 기본 '보통'은 약 360×400 논리 px다.
- **작고 차분한 중성색**으로 한다. 옆자리에서 힐끗 봐도 튀지 않게 하기 위해서다. OS 다크/라이트 테마를 따라가고, 기물·숫자는 단순한 모양으로 그린다.
  - time-keeper의 레트로 감성과 '엑셀 위장'은 버렸다. 눈에 띄거나 디자인 부담이 크다.

## 설정 (구현 완료 #36 — `src/shared/settings.ts`, `src/main/settingsService.ts`, `views/SettingsView.tsx`)
기기별 `userData/settings.json`. 설정 창(평범한 창)에서 바꾸면 바로 저장되고 패널·트레이에 반영된다. 떠 있던 패널은 숨겨지고, 다음에 뜰 때 새 모서리·크기로 뜬다. 항목:
- 핫존 모서리 (기본 오른쪽 위)
- 나타나기 지연 (기본 500ms, 0.2~1.5초를 0.1초 단위로)
- 패널 크기 (기본 보통) — 작게 0.85배(306×340) · 보통 360×400 · 크게 1.2배(432×480). 화면은 CSS `zoom`, 창은 같은 배율.
- 트레이 아이콘 표시 (기본 켬)
- 화면 공유에서 숨김 (기본 켬)
- 스도쿠 틀린 칸 표시 (기본 켬)
- 언어: 시스템 언어 / 한국어 / English (시스템 언어는 OS가 한국어면 한국어, 그 밖은 영어)
- 설정 창 아래 [앱 종료]. 트레이를 꺼도 종료할 수 있게.

## 언어 (구현 완료 #37 — `src/shared/labels.ts`, `src/renderer/src/i18n.ts`)
- 한국어·영어 두 묶음으로 둔다. 화면·트레이·창 제목 문구를 모두 묶음에서 가져온다(time-keeper `labels.ts` 방식을 복사하되, 앱끼리 코드를 공유하지는 않는다).
- 톤은 두 언어 모두 짧은 반말(예: 네 차례 / Your move, 다 풀었다! / Solved it!). 언어 이름은 그 언어로 쓴다(한국어 / English) — 못 읽는 언어로 바꿔도 돌아올 수 있게.
- 영어는 패널 툴바가 좁아서 [새 판]을 `New`, 확인을 `Sure?`로 줄였다. 설정 창은 영어 문구가 길어 높이를 660으로 잡고 스스로 스크롤하게 했다.

- ~~옆 모니터와 맞닿은 모서리~~ — #45에서 모니터·모서리 고르기와 막힌 모서리 비활성으로 해결.
- Electron `display.id`가 재부팅·드라이버 갱신 뒤에도 같은지는 확인하지 못했다. 바뀌면 주 모니터로 돌아가고 설정 창이 알려 준다.

- macOS에서 다른 앱의 전체 화면 Space 위에 패널을 띄우는 방법(`setVisibleOnAllWorkspaces` + `alwaysOnTop` 레벨).
