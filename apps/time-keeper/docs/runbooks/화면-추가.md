# 런북: 화면 추가

목적: 새 화면(탭 또는 창)을 추가한다. 예: 통계 탭(#6), 설정 화면, 미니 모드 창(#5).

## 수정할 파일 (순서대로)
1. `src/renderer/src/` — 화면 컴포넌트 파일 추가 (예: `StatsView.tsx`). 상태는 `App.tsx`처럼 `window.api.getState()` + `window.api.onChanged()`로 받는다.
2. 시간 계산이 필요하면 `src/shared/timer.ts`의 함수(`totalsBetween`, `startOfDay`, `formatHMS`)를 쓰고, 없는 계산은 거기에 순수 함수로 추가 + 테스트.
3. 화면 문구는 `src/shared/labels.ts`의 `Messages`에 항목을 추가하고 `ko`·`en` 둘 다 채운다. 컴포넌트에서는 `const t = useT()` 후 `t.<항목>`.
4. 스타일은 `src/renderer/src/assets/main.css` — 맨 위 디자인 토큰만 쓴다(레트로 주방 타이머, `docs/design.md > 디자인`). 분야 색은 `.cat-*`의 `--cat`/`--cat-edge`. 숫자 표시는 `components/Lcd.tsx`, 버튼은 `.key` 클래스를 재사용한다.
5. **탭이면** `src/renderer/src/App.tsx`에서 탭 전환으로 렌더링.
   **새 창이면** `src/shared/view.ts`의 `VIEW_MODES`와 `src/main/windows.ts`의 `SPECS`(크기·미니 여부)에 추가하고, `src/renderer/src/views/`에 화면을 만들어 `App.tsx`에서 해시로 연결한다. 창 띄우기는 `window.api.openView('<mode>')`.

## 실행
```bash
npm run dev
```

## 검증
- `npm run typecheck && npm run lint` 통과.
- `npm run dev`로 화면을 열어 타이머를 돌리며 다른 창·탭과 시간이 같이 움직이는지 확인.
- 라이트/다크 모드(OS 설정) 둘 다에서 글자가 보이는지 확인.

## 흔한 함정
- 화면마다 `setInterval`로 시간을 더하지 말 것 — 항상 `now - startedAt`.
- 새 창은 `webPreferences.preload`를 빼먹으면 `window.api`가 없다.
- `CHANGELOG.md`의 `[Unreleased]`에 한 줄 추가.
