# Changelog — time-keeper

이 앱의 모든 변경 사항을 기록한다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/), 버전은 [Semantic Versioning](https://semver.org/lang/ko/)을 따른다.

- 첫째 자리(MAJOR): 사용법이 바뀌거나 데이터가 호환되지 않는 변경
- 둘째 자리(MINOR): 기능 추가
- 셋째 자리(PATCH): 버그 수정·자잘한 손질

항목 분류: `Added`(추가) · `Changed`(변경) · `Deprecated`(곧 제거) · `Removed`(제거) · `Fixed`(버그 수정) · `Security`(보안)

## [Unreleased]
### Added
- 앱 생성: Electron + React + Vite + TS 뼈대, Windows(.exe)·macOS(.dmg) 설치 파일 설정 (#2)
- 일·쉼·공부 분야 버튼으로 고르고(일 준비) 시작 버튼으로 기록 시작, 종료 버튼으로 끝내기. 진행 중에 다른 분야를 골라 시작하면 진행 중인 기록이 자동으로 끝나고 전환 (#2, #12)
- 상태 표시: 대기 / 준비 / 진행 중 (#12)
- 화면·트레이·종료 확인창 문구를 능청스러운 반말로 — "멍 때리는 중", "뇌 키우는 중 🧠", "가보자고", "진짜 끌 거야?" (#14)
- 미니 모드: 숫자 미니(작은 액정 리모컨)와 시계 미니(분침만 도는 다이얼). 항상 위·끌어서 이동·"다시 크게" 버튼(또는 더블클릭)으로 기본 창 (#5)
- 기본 창 "맨 위에 박제" 토글, 트레이 메뉴에서 세 모드 중 하나로 열기 (#5)
- 레트로 주방 타이머 디자인: 민트 본체, 7세그먼트 LCD, 눌린 채 걸리는 분야 키와 깜빡이는 준비 LED (#5)
- 통계 탭: 오늘·이번 주·이번 달·직접 지정 기간의 분야별 합계와 비율, 날마다 누적 막대(마우스 올리면 그날 값) (#6)
- 설정 탭: 본체 색을 프리셋 클릭 또는 R·G·B 입력으로 바꾸기 (미니 모드 포함, 글자색 자동) (#21)
- 오늘의 성적표 접기/펼치기, 접으면 창 높이도 줄어듦 (상태 기억) (#21)
- 한국어/영어 지원: 설정에서 시스템 언어·한국어·English, 트레이 메뉴·종료 확인창·창 제목 포함 (#8)
- 구글 드라이브 동기화: 내 OAuth 클라이언트로 연결해 기기별 기록 파일을 올리고 다른 기기 기록을 통계에 합침. 자동(시작·1분마다·시작/종료 후) + 지금 동기화, 오프라인에서도 마지막으로 받은 기록 표시 (#7)
- 여러 컴퓨터 자동 이어받기: 다른 컴퓨터에서 도는 타이머는 여기서 시작한 시각에 끝내고 양쪽에 알림 (설정에서 끌 수 있음) (#7)
- 폴더로 동기화: 구글 드라이브 데스크톱·Dropbox·OneDrive·iCloud 폴더를 고르기만 하면 연결 (로그인·키 없음), 이 컴퓨터의 클라우드 폴더를 찾아 원클릭으로 제시 (#25)
- 구글 계정 연결 쉽게: 키 파일 끌어다 놓기/불러오기, 다른 컴퓨터용 연결 코드 (#25)
- 경과 시간 시:분:초 표시, 오늘 분야별 합계 (#2)
- 기록을 내 컴퓨터에 저장. 앱 종료·절전 시 그 시각으로 기록 마감, 비정상 종료 시 마지막 확인 시각으로 마감 (#2)
- `time-keeper/v*` 태그로 설치 파일을 빌드해 GitHub Releases에 올리는 워크플로 (#2)
- 창 닫기(X)는 트레이로 숨기기. 트레이 아이콘에 현재 분야·경과 시간 표시, 메뉴에서 열기/종료 (#4)
- 기록 진행 중 종료하면 확인창 표시 (트레이 종료, mac Cmd+Q) (#4)
- 앱을 두 번 실행하면 새로 열지 않고 기존 창을 띄움 (#4)
