2026-10-19 grill 인터뷰로 합의한 내용. 구현 상태는 각 항목의 이슈 번호로 추적한다.

## 형태·배포
- Windows `.exe`(NSIS) / macOS `.dmg`(universal) 데스크톱 앱. Electron + React + Vite + TypeScript.
- 태그 `time-keeper/v*` 푸시 → `.github/workflows/time-keeper-release.yml`이 두 OS를 빌드해 GitHub Releases에 업로드.
- 코드 서명 없음. 첫 실행 보안 경고 우회법은 `README.md`에 안내.
- 새 버전 알림만 (자동 설치 없음 — 미서명 mac은 자동 업데이트 불가). 릴리스 중 `time-keeper/v*` 태그만 비교. → #9

## 타이머 규칙 (0.1.0 구현 완료 — `src/shared/timer.ts`)
- 분야는 `work`(일) · `break`(쉼) · `study`(공부) 3개 고정. 데이터는 문자열 id라 이후 분야 추가 가능.
- 한 번에 하나만 진행. 다른 분야 시작 = 현재 기록을 그 시각으로 마감하고 전환. 같은 분야 재클릭은 무시.
- **고르고 → 시작 2단계** (#12에서 변경, 사용자 피드백): 분야 버튼은 "준비"만 하고, [시작]을 눌러야 기록이 바뀐다.
  `대기 중` →[일]→ `일 준비` →[시작]→ `일하는 중` →[종료]→ `대기 중`
  - 진행 중에 다른 분야를 고르면 현재 기록은 계속 세고 "→ 쉼 준비"를 표시. [시작]을 누르는 순간 마감·전환.
  - 준비된 분야나 진행 중인 분야를 다시 누르면 선택 해제. 선택값은 화면 상태라 저장하지 않는다 (`select`, `canStart`).
  - 위 흐름의 상태 이름(대기 중·일 준비·일하는 중)은 설계용 이름이다. 화면 문구는 아래 "문구 톤"을 따른다.

## 문구 톤 (#14, 사용자 확정)
능청스러운 반말. 영어도 같은 톤(예: Zoning out, Growing brain 🧠, Let's go, Really quitting?). 실제 문구는 `src/shared/labels.ts`의 `ko`·`en`이 기준이다.

| 자리 | 문구 |
|---|---|
| 대기 | 멍 때리는 중 |
| 준비 (일/쉼/공부) | 돈...벌어야겠지? / 숨고르기 / 이제 진짜 공부뿐이야 |
| 진행 중 (일/쉼/공부) | 돈 버는 중 💸 / 충전 중 🔋 / 뇌 키우는 중 🧠 |
| 시작 / 종료 버튼 | 가보자고 / 그만! |
| 오늘 합계 제목 | 오늘의 성적표 |
| 트레이 메뉴 | 나와봐 / 오늘은 여기까지 |
| 종료 확인창 | 진짜 끌 거야? — "잠깐, 뇌 키우던 중이잖아!" / 끄면 지금까지만 기록돼. / [그래도 끌래] [아 맞다, 더 할게] |
- 종료 버튼 = 마감 후 대기 상태.
- 시간은 `now - startedAt`으로 계산, `시:분:초` 표시 (ms 없음).
- 앱 종료 → 종료 시각으로 마감. 절전 진입 → 그 시각으로 마감, 깨어나도 재시작 안 함.
- 강제 종료·정전 → 30초 간격 heartbeat의 마지막 시각으로 다음 실행 때 마감 (최대 ~30초 오차).

## 창·트레이 (구현 완료 #4 — `src/main/index.ts`, `src/main/tray.ts`)
- X 버튼 = 트레이(숨겨진 아이콘)로 숨김, 타이머 계속.
- 트레이 메뉴의 종료 = 진행 중이면 확인창 → 마감 후 종료.
- 트레이 툴팁에 현재 분야와 경과 시간.

## 화면 (구현 완료 #5 — `src/main/windows.ts`, `src/renderer/src/views/`)
- **기본 모드**: 타이머 / 통계 탭, 📌 항상 위 토글, 설정(톱니바퀴).
- **디지털 미니**: 분야 · `시:분:초` · 작은 버튼 5개(일/쉼/공부 + 시작/종료 — 기본 모드와 같은 고르고→시작 흐름).
- **아날로그 미니**: 분침 하나. 기록 시작 시 12시 방향에서 출발해 60분에 한 바퀴. 분야는 테두리 색. 숫자 시간 없음. 호버 시 버튼.
- 미니 공통: 항상 위, 드래그 이동, **늘 보이는 "다시 크게" 버튼**(사용자 피드백: 더블클릭만으로는 돌아가는 법이 안 보임) 또는 더블클릭 → 기본 모드.
- 언어: 한국어/영어 (구현 완료 #8). 설정 > 언어 [시스템 따라가기 | 한국어 | English]. 시스템 따라가기는 OS 언어가 한국어면 한국어, 그 밖은 영어. 트레이 메뉴·종료 확인창·창 제목까지 함께 바뀐다.

## 디자인 (#5, 사용자 확정: 레트로 주방 타이머)
첫 디자인(어두운 배경 + 강조색 3개)이 "밤티 난다"는 피드백으로 바꿨다. 기준 토큰은 `src/renderer/src/assets/main.css` 맨 위.
- **본체**: 파스텔 민트 플라스틱 `#B9DEC9`, 테두리 `#8FC4AB`. 가전처럼 색이 하나라 다크 모드는 두지 않는다.
- **LCD 창** (눈에 띄는 요소는 이것 하나): 회녹색 `#C9D4B2`, 숫자는 DSEG7 7세그먼트 글꼴, 뒤에 꺼진 세그먼트 `88:88:88`을 흐리게 깔아 실제 액정처럼.
- **키**: 아래 두께가 있는 플라스틱 키. 진행 중인 분야 키는 눌린 채 걸려 있고(래칭), 준비된 분야는 키 위 LED가 깜빡인다.
  분야 색: 일 버터 노랑 `#F3C343` · 쉼 하늘 `#7EC3E4` · 공부 토마토 `#E5533C`.
- **디지털 미니**: 작은 LCD 리모컨 (LCD + 작은 키 5개).
- **아날로그 미니**: 주방 다이얼 타이머. 흰 다이얼, 분 눈금, 빨간 바늘, 12시엔 숫자 대신 삼각 표식(바늘 출발점), 분야는 다이얼 테두리 색. 키 줄은 호버 시 다이얼 **위쪽 바깥**에 나타난다(다이얼 안에 두면 눈금과 겹쳐 안 읽힘). 다이얼은 남은 공간에 맞춰 줄어들어 디스플레이 배율이 달라도 잘리지 않는다.
- 툴바 아이콘은 이모지가 아닌 선 아이콘(`components/Icons.tsx`).

## 설정 (구현 완료 #21 — `views/SettingsView.tsx`, `src/shared/settings.ts`, `theme.ts`)
- 기본 창 탭 [타이머] [통계] [설정]. 설정은 기기별 `userData/settings.json`.
- **본체 색** (사용자 요청): 프리셋 6개(민트·버터·하늘·라벤더·복숭아·차콜) 클릭 또는 R·G·B(0~255) 입력. 본체만 바뀌고 LCD·키 색은 유지(사용자 결정). 미니 모드에도 적용. 글자색은 자동(대비 4.5:1 보장).
- **오늘의 성적표 접기** (사용자 요청): 제목 옆 [접기/펼치기] 버튼. 창 크기는 그대로(사용자 결정). 접힘 상태는 설정에 저장.
- **언어** (#8): [시스템 따라가기 | 한국어 | English].

## 통계 (구현 완료 #6 — `src/shared/stats.ts`, `views/StatsView.tsx`, `components/DailyChart.tsx`)
- 기본 창 상단 탭 [타이머] [통계]. 통계 탭: 기간 [오늘][이번 주][이번 달][직접(시작일~종료일)].
- 비율 막대 + 분야별 합계·비율 표(범례 겸 표). 오늘이 아니면 일별 누적 막대(아래→위 일·쉼·공부), 막대에 마우스를 올리면 그날 값.
- 차트 막대 색은 키 색의 진한 단계(일 `#B07D12` · 쉼 `#2F7FAE` · 공부 `#D2402A`) — 키 색은 밝아 막대로 쓰면 안 보여서, dataviz 검증 스크립트(밝기·채도·색각이상·대비)로 통과한 값.
- 두 달이 넘는 직접 지정 기간은 합계만 보여준다.
- 자정을 넘긴 기록은 날짜별로 나눠 집계 (기기 현지 시각). `totalsBetween`이 구간으로 잘라 계산한다.
- 0.1.0 제외: 기록 목록·수정·삭제, CSV 내보내기.

## 데이터·동기화 → #7
- **시각 저장 규칙** (사용자 확인): 기록 시각은 epoch ms(UTC 기준 절대 시각)로만 저장하고, 날짜 나누기·표시는 보는 기기의 현지 시간대로 한다. 윤년·월 길이·서머타임은 달력 단위 이동(`setDate`/`setMonth`)으로 OS 시간대 데이터가 처리한다. 동기화로 다른 시간대 기기의 기록이 합쳐져도 같은 규칙으로 보인다.
- **로컬 우선**: 항상 `userData/time-keeper-data.json`에 먼저 저장 (구현 완료 — `src/main/store.ts`). 로그인 없이 사용 가능.
- **구글 드라이브**: 각 기기는 자기 파일 `sessions-<deviceId>.json`에만 쓰고, 통계는 모든 기기 파일을 합쳐 계산 → 쓰기 충돌 없음.
- **OAuth 키는 사용자가 직접 발급·입력** (사용자 결정). 레포·빌드에 키가 없다. 입력값은 `safeStorage`로 암호화 저장.
  - 데스크톱 OAuth(PKCE + 루프백), scope는 `drive.file` 하나.
  - 안내 필수: 동의 화면을 **프로덕션으로 게시** (테스트 상태면 7일마다 로그아웃). 미검증 앱 경고가 1회 뜰 수 있음.
- 저장소는 인터페이스로 분리해 노션을 이후 버전에 추가할 수 있게 한다.
