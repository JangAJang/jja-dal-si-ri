# jja-dal-si-ri (짜달시리)

일상과 업무에서 쓰는 짜달시리한(자잘한) 애플리케이션들을 한곳에 모아두는 저장소입니다.
앱 하나는 `apps/` 아래 폴더 하나이고, 각 앱은 서로 독립적으로 실행됩니다.

## 앱 목록

<!-- 앱을 추가하거나 버전을 올리면 이 표도 같은 커밋에서 함께 고칩니다. -->
| 앱 | 설명 | 현재 버전 | 상태 | 주소 | 변경 이력 |
|----|------|----------|------|------|----------|
| [짜달시리 타이머](apps/time-keeper) | 일·쉼·공부 시간을 기록하고 분야별로 얼마나 썼는지 보는 데스크톱 타이머 (Windows·Mac) | - (첫 릴리스 전) | 개발중 | [다운로드](https://github.com/JangAJang/jja-dal-si-ri/releases) | [CHANGELOG](apps/time-keeper/CHANGELOG.md) |

- **상태**: `개발중`(0.x) · `사용중`(1.0 이상) · `보관`(더 이상 손대지 않음)
- **주소**: `docker compose up` 후 브라우저에서 열 주소입니다. 화면이 없는 앱은 `-`로 둡니다.

## 버전은 어떻게 매기나요

앱마다 따로 버전을 매깁니다. 형식은 `큰변경.기능추가.버그수정`(예: `1.4.2`)입니다.

| 이런 변경이면 | 이 자리를 올립니다 | 예시 |
|---|---|---|
| 기존 사용법이 바뀌거나 데이터가 호환되지 않음 | 첫째 자리 | `1.4.2` → `2.0.0` |
| 새 기능 추가 | 둘째 자리 | `1.4.2` → `1.5.0` |
| 버그 수정·자잘한 손질 | 셋째 자리 | `1.4.2` → `1.4.3` |

새 앱은 `0.1.0`에서 시작하고, 실제로 쓸 만해지면 `1.0.0`으로 올립니다.
각 버전에서 무엇이 바뀌었는지는 앱 폴더의 `CHANGELOG.md`에 적혀 있습니다.

## 앱 실행 방법

1. Docker Desktop이 켜져 있는지 확인합니다.
2. 실행하려는 앱 폴더로 이동해서 아래를 실행합니다.

   ```bash
   cd apps/<앱이름>
   docker compose up
   ```
3. 위 표의 **주소** 칸에 적힌 주소를 브라우저에서 엽니다.

## 주의

- `main`에 직접 올리지 않습니다. 모든 작업은 `leejanghee/<작업종류>/<앱이름>/<이슈번호>/<작업-제목>` 브랜치에서 하고 PR로 합칩니다.
- 앱끼리 코드를 공유하지 않습니다. 비슷한 코드가 필요하면 각 앱에 따로 둡니다.
- 비밀번호나 API 키는 `.env` 파일에만 두고 커밋하지 않습니다.
