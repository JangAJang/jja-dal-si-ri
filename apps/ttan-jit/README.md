# 짜달시리 딴짓 (ttan-jit)

화면 모서리에 마우스를 잠깐 올려 두면 체스판이나 스도쿠가 나타나고, 마우스를 치우면 아무것도 없었던 것처럼 사라지는 딴짓 앱입니다.
숨기는 순간 게임은 멈추고, 다음에 다시 띄우면 하던 판에서 이어서 합니다.

> 첫 버전(0.1.0)의 기능이 모두 들어갔습니다. 아직 릴리스 전입니다.
> 기능 설계는 [docs/design.md](docs/design.md)에 정리되어 있습니다.

## 설치 방법

[다운로드 페이지](https://github.com/JangAJang/jja-dal-si-ri/releases)에서 `ttan-jit/`로 시작하는 최신 버전을 찾아 내 컴퓨터에 맞는 파일을 받습니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `ttan-jit-<버전>-setup.exe` |
| Mac | `ttan-jit-<버전>-universal.dmg` |

이 앱은 유료 인증서로 서명하지 않아서, 처음 실행할 때 경고가 한 번 뜹니다.

- **Windows**: "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
- **Mac**: `.dmg`를 열어 앱을 응용 프로그램 폴더로 옮긴 뒤, 앱을 **우클릭 → 열기** → **열기**를 누릅니다.
  ("손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 `xattr -cr "/Applications/짜달시리 딴짓.app"` 실행 후 다시 엽니다.)

## 사용 방법

마우스를 화면 **오른쪽 위 모서리**(처음 설정, 주 모니터)에 0.5초 올려 두면 게임 패널이 나타납니다. 모니터가 여러 대면 아래 **설정 > 나타날 자리**에서 바꿀 수 있습니다. 마우스를 패널 밖으로 빼면 바로 사라집니다.
패널이 떠도 지금 쓰던 프로그램의 입력은 끊기지 않습니다. 키보드로 게임을 하려면 패널을 한 번 클릭합니다.
숨기는 순간 게임은 멈추고, 앱을 껐다 켜도 하던 판에서 이어집니다.

### 설정

패널 오른쪽 위 톱니바퀴, 또는 트레이 아이콘(점 9개)의 **설정**으로 엽니다. 바꾸면 바로 적용됩니다.

- **나타날 자리**: 모니터 배치 그림에서 패널을 띄울 모니터의 모서리를 누릅니다. 흐린 모서리는 옆 모니터와 맞닿아 마우스가 넘어가 버리는 곳이라 고를 수 없습니다. 고른 모니터를 빼면 주 모니터에 뜹니다.
- **나타나기까지**: 모서리에 마우스를 몇 초 올려 둬야 뜰지 (0.2~1.5초).
- **패널 크기**: 작게 / 보통 / 크게.
- **트레이 아이콘 보이기**: 끄면 아이콘도 사라집니다. 설정 창을 다시 열려면 **앱을 한 번 더 실행**합니다.
- **화면 공유·스크린샷에서 숨기기**: 켜 두면 회의 화면 공유나 캡처에 패널이 찍히지 않습니다.
- **언어**: 시스템 언어 / 한국어 / English. 시스템 언어는 컴퓨터 언어가 한국어면 한국어, 그 밖은 영어입니다. 트레이 메뉴도 같이 바뀝니다.
- **앱 종료**: 앱을 끕니다(하던 판은 저장됩니다).

### 스도쿠

- 칸을 누르고 숫자 키(또는 아래 숫자 버튼)로 넣습니다. 같은 숫자를 다시 넣으면 지워집니다. 틀린 숫자는 빨간색으로 보입니다.
- **메모**(또는 `N`)를 켜면 숫자가 작은 메모로 들어갑니다. 숫자를 넣으면 같은 줄·칸 묶음의 그 숫자 메모는 저절로 지워집니다.
- **지우기**(`Backspace`), **되돌리기**(`Ctrl+Z`), 화살표로 칸 이동.
- 난이도(쉬움·보통·어려움)를 고르고 **새 판**을 누릅니다. 하던 판이 있으면 한 번 더 눌러야 바뀝니다.
- 오른쪽 위 시간은 패널이 떠 있는 동안만 흐릅니다.

### 체스

- 컴퓨터와 둡니다. 내 기물을 누르면 갈 수 있는 칸에 점이 찍히고, 그 칸을 누르거나 기물을 끌어다 놓으면 둡니다.
- 컴퓨터가 생각하는 동안에는 위에 "생각 중…"이 뜹니다. 패널을 숨겨도 컴퓨터는 수를 두고, 다음에 띄우면 보입니다.
- 난이도(쉬움·보통·어려움·매우 어려움)와 내 색(백·흑·무작위)을 고르고 **새 판**을 누릅니다. 하던 판이 있으면 한 번 더 눌러야 바뀝니다.
- 폰이 끝 줄에 닿으면 퀸이 됩니다.
- **무르기**: 내 마지막 수(와 컴퓨터가 받아 둔 수)를 되돌립니다. 여러 번 누를 수 있고, 진 판에서도 됩니다.

## 개발

```bash
npm install
npm run dev
```
