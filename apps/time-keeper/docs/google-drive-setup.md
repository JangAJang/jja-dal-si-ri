# 다른 컴퓨터와 기록 맞추기

짜달시리 타이머는 서버가 없습니다. 기록은 **내 클라우드**에 올라가고, 각 컴퓨터가 그걸 읽어 통계에 합칩니다.
방법은 두 가지입니다. 대부분은 **방법 1**이면 충분합니다.

| | 방법 1. 폴더로 동기화 (추천) | 방법 2. 구글 계정으로 연결 (내 키) |
|---|---|---|
| 준비 | 구글 드라이브 데스크톱·Dropbox·OneDrive·iCloud 중 하나가 깔려 있으면 끝 | Google Cloud 에서 열쇠 만들기 (처음 한 번, 10분쯤) |
| 연결 | 폴더 하나 클릭 | 열쇠 넣고 브라우저 로그인 |
| 다른 컴퓨터 | 같은 클라우드 폴더 클릭 | 연결 코드 붙여 넣기 |

## 방법 1. 폴더로 동기화 (추천)

1. 쓰는 컴퓨터마다 클라우드 앱을 깔고 같은 계정으로 로그인합니다.
   - [구글 드라이브 데스크톱](https://www.google.com/drive/download/), Dropbox, OneDrive(Windows 기본), iCloud 중 아무거나.
2. 짜달시리 타이머 → **설정** 탭 → **다른 컴퓨터와 동기화**.
3. **이 컴퓨터에서 찾은 폴더**에 나온 것(예: `구글 드라이브 — G:\내 드라이브`)을 누릅니다.
   안 보이면 **다른 폴더 고르기…** 로 클라우드 앱이 동기화하는 폴더를 직접 고르세요.
4. "마지막 동기화 방금"이 보이면 끝. 다른 컴퓨터에서도 **같은 클라우드의 폴더**를 고르면 서로의 기록이 보입니다.

- 고른 폴더 안에 `Jjadalsiri Timer` 폴더가 생기고, 그 안에 컴퓨터마다 파일이 하나씩 생깁니다.
- 다른 컴퓨터로 옮겨지는 속도는 클라우드 앱에 달려 있습니다(보통 몇 초~1분).
- 클라우드 앱이 꺼져 있거나 드라이브가 빠지면 "폴더에 접근할 수 없어"가 뜹니다. 다시 켜지면 저절로 이어집니다.
- 클라우드 앱이 만드는 충돌 사본(`… (1).json`)이 생겨도 기록이 두 번 세지지 않습니다.

## 방법 2. 구글 계정으로 연결 (내 키 쓰기)

클라우드 앱을 깔고 싶지 않을 때 씁니다. 앱이 내 구글 드라이브에 직접 올리는데, 그 열쇠(OAuth 클라이언트)를 **내가 직접** 만듭니다.

> 왜 직접 만드나요? 앱을 공개 저장소에서 나눠 주기 때문에 열쇠를 앱에 넣어 두면 누구나 꺼내 쓸 수 있습니다.
> 각자 자기 열쇠를 쓰면 그런 걱정이 없고, 앱은 **이 앱이 만든 파일만** 볼 수 있습니다(`drive.file` 권한). 내 드라이브의 다른 파일은 보지 못합니다.

화면 이름은 구글 클라우드 콘솔이 바뀌면 조금 다를 수 있습니다.

### 1) 프로젝트 만들기

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 내 구글 계정으로 들어갑니다.
2. 위쪽의 프로젝트 선택 → **새 프로젝트** → 이름은 아무거나(예: `jjadalsiri-timer`) → **만들기**.

### 2) 구글 드라이브 API 켜기

1. 메뉴 → **API 및 서비스** → **라이브러리**.
2. `Google Drive API`를 찾아 → **사용**(Enable).

### 3) 동의 화면 만들기

1. 메뉴 → **Google Auth Platform** → **브랜딩**(Branding).
2. 앱 이름(예: `짜달시리 타이머`)과 사용자 지원 이메일(내 이메일)을 넣고 **다음**.
3. 대상(Audience)은 **외부**(External)를 고르고, 연락처 이메일을 넣은 뒤 **만들기**.
4. **데이터 액세스**(Data Access) → **범위 추가 또는 삭제** → `.../auth/drive.file`(Google Drive API, "이 앱으로 연 파일만") 체크 → **저장**.

### 4) 앱 게시하기 ⚠️ 꼭 하세요

1. **대상**(Audience) 화면에서 **앱 게시**(Publish app) → 확인.
2. 게시 상태가 **프로덕션 단계**(In production)가 됐는지 확인합니다.

이걸 안 하면 앱이 "테스트" 상태로 남아서 **7일마다 로그인이 풀립니다** (구글 정책).
`drive.file`은 구글이 "민감하지 않은 권한"으로 분류해, 구글 심사 없이 게시해도 됩니다.

### 5) 클라이언트(열쇠) 만들기

1. **Google Auth Platform** → **클라이언트**(Clients) → **클라이언트 만들기**.
2. 애플리케이션 유형: **데스크톱 앱**(Desktop app). 이름은 아무거나 → **만들기**.
3. **JSON 다운로드**로 키 파일(`client_secret_….json`)을 받아 둡니다.

### 6) 앱에 넣고 연결하기

1. 짜달시리 타이머 → **설정** 탭 → **다른 컴퓨터와 동기화** → **구글 계정으로 연결 (내 키 쓰기)** 펼치기.
2. 받은 키 파일을 그 칸으로 **끌어다 놓거나** **키 파일 불러오기**로 고릅니다. (ID·비밀번호를 직접 붙여 넣어도 됩니다.)
3. **구글로 연결** → 브라우저에서 내 구글 계정을 고르고 허용합니다.
   - 만약 "Google에서 확인하지 않은 앱" 화면이 나오면, 내가 만든 앱이니 **고급** → **(앱 이름)(으)로 이동**을 누르세요.
4. 브라우저에 "연결됐어!"가 뜨면 닫아도 됩니다. 앱에 "마지막 동기화 방금"이 보이면 끝.

### 다른 컴퓨터에서

1. 연결한 컴퓨터에서 **다른 컴퓨터용 연결 코드 복사**를 누릅니다.
2. 다른 컴퓨터의 **연결 코드** 칸에 붙여 넣고 **구글로 연결** → 같은 구글 계정으로 로그인.

연결 코드에는 열쇠가 들어 있으니 내 컴퓨터끼리만 쓰세요. `drive.file` 권한은 "이 열쇠로 만든 파일"만 보이기 때문에, 컴퓨터마다 다른 열쇠를 만들면 서로의 기록이 안 보입니다.

## 알아 두면 좋은 것 (두 방법 공통)

- **언제 동기화되나요?** 앱을 켤 때, 1분마다, 시작·종료하고 3초 뒤, 그리고 **지금 동기화**를 누를 때. 바뀐 게 없으면 올리지 않습니다.
- **여러 컴퓨터에서 동시에 켜면?** 노트북에서 타이머가 도는 중에 데스크톱에서 시작하면, 노트북 기록은 **데스크톱에서 시작한 시각**에 자동으로 끝납니다(1분 안에, 노트북이 꺼져 있었다면 다음에 켤 때). 양쪽에 알림이 뜹니다. 일부러 두 곳에서 동시에 기록하고 싶으면 설정의 **다른 컴퓨터 타이머 자동으로 끄기**를 끄세요.
- **올라가는 것:** 컴퓨터마다 `sessions-<기기ID>.json` 파일 하나(끝난 기록, 지금 도는 기록, 컴퓨터 이름). 컴퓨터마다 자기 파일에만 써서 서로 덮어쓰지 않습니다.
- **인터넷이 없어도** 타이머·통계는 그대로 됩니다. 다른 컴퓨터 기록은 마지막으로 받아 둔 것이 보이고, 연결되면 다시 맞춥니다.
- **열쇠는 어디 저장되나요? (방법 2)** 이 컴퓨터의 운영체제 보안 저장소(Windows DPAPI / macOS 키체인)로 암호화해서 앱 데이터 폴더에 둡니다.
- **연결 끊기**를 누르면 이 컴퓨터의 설정과 받아 둔 기록을 지웁니다(방법 2는 구글 쪽 권한도 철회). 클라우드에 올라간 파일은 그대로 남습니다.
- **"로그인이 풀렸어" (방법 2)** 가 뜨면: 4)앱 게시를 했는지 확인하고 **다시 연결**하세요.
