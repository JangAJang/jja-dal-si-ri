# 짜달시리 타이머 (time-keeper)

일한 시간, 쉬는 시간, 공부한 시간을 버튼 하나로 기록하는 데스크톱 타이머입니다.
분야를 고르고 **가보자고**를 누르면 기록이 시작되고, 일하는 중에 **쉼**을 골라 **가보자고**를 누르면 일한 시간이 자동으로 끝나고 쉬는 시간이 시작됩니다.
기록은 내 컴퓨터에 저장되고, 오늘 분야별로 얼마나 썼는지 바로 볼 수 있습니다.

> 지금은 첫 버전을 만드는 중입니다. 통계 화면, 미니 모드, 구글 드라이브 동기화는 차례로 추가됩니다.
> 앞으로 들어갈 기능은 [docs/design.md](docs/design.md)에 정리되어 있습니다.

## 설치 방법

[다운로드 페이지](https://github.com/JangAJang/jja-dal-si-ri/releases)에서 `time-keeper/`로 시작하는 최신 버전을 찾아 내 컴퓨터에 맞는 파일을 받습니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `time-keeper-<버전>-setup.exe` |
| Mac | `time-keeper-<버전>-universal.dmg` |

이 앱은 유료 인증서로 서명하지 않아서, 처음 실행할 때 경고가 한 번 뜹니다.

- **Windows**: "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
- **Mac**: `.dmg`를 열어 앱을 응용 프로그램 폴더로 옮긴 뒤, 앱을 **우클릭 → 열기** → **열기**를 누릅니다.
  ("손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 `xattr -cr "/Applications/짜달시리 타이머.app"` 실행 후 다시 엽니다.)

## 사용 방법

아무것도 안 하고 있으면 위에 "멍 때리는 중"이 떠 있습니다.

- **일 / 쉼 / 공부**: 분야를 고릅니다. 위에 "돈...벌어야겠지?", "숨고르기", "이제 진짜 공부뿐이야"처럼 표시되고, 아직 기록은 시작되지 않습니다. 같은 버튼을 다시 누르면 선택이 풀립니다.
- **가보자고**: 고른 분야의 기록을 시작합니다. 위의 표시가 "돈 버는 중 💸", "충전 중 🔋", "뇌 키우는 중 🧠"으로 바뀝니다.
  - 다른 분야가 돌고 있을 때 새 분야를 고르면, 지금 기록은 계속되면서 "→ 숨고르기"처럼 다음 분야가 표시됩니다. **가보자고**를 누르는 순간 지금 기록이 끝나고 새 분야로 넘어갑니다.
- **그만!**: 지금 돌고 있는 기록을 끝냅니다.
- **오늘의 성적표**: 오늘 분야별로 쓴 시간입니다.
- **창 닫기(X)**: 앱이 꺼지지 않고 트레이로 숨습니다. 기록은 계속됩니다.
  - Windows: 작업 표시줄 오른쪽 `^`(숨겨진 아이콘)에 있습니다. 클릭하면 창이 다시 열립니다.
  - Mac: 화면 위쪽 메뉴바에 있습니다.
  - 아이콘에 마우스를 올리면 "뇌 키우는 중 🧠 01:23:45"처럼 지금 상태가 보입니다.
- **앱 끄기**: 트레이 아이콘 우클릭 → **오늘은 여기까지**. 기록이 진행 중이면 "진짜 끌 거야?" 하고 한 번 더 묻습니다. (창을 다시 열려면 **나와봐**)
- 앱을 끄거나 컴퓨터가 절전 모드로 들어가면, 그 시각에 기록이 자동으로 끝납니다.

### 작게 띄워 두기 (미니 모드)

창 오른쪽 위의 작은 동그란 버튼으로 바꿉니다. 트레이 메뉴의 **쪼그맣게 (숫자)** / **쪼그맣게 (시계)** 로도 열 수 있습니다.

- **숫자 미니**: 작은 액정 리모컨처럼 생겼습니다. 상태·시간과 작은 버튼(일·쉼·공부·▶·■)이 있습니다.
- **시계 미니**: 주방 다이얼 타이머처럼 생겼습니다. 숫자 시간 없이 빨간 바늘 하나가 기록 시작부터 60분에 한 바퀴 돕니다. 테두리 색이 지금 분야입니다. 마우스를 올리면 다이얼 위쪽에 버튼 줄이 나타납니다.
- 미니는 항상 다른 창 위에 떠 있고, 잡고 끌어서 옮길 수 있습니다. **더블클릭하면 다시 커집니다.**
- 기본 창의 핀 버튼(**맨 위에 박제**)을 누르면 기본 창도 항상 위에 떠 있습니다.
